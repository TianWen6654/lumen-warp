# Lumen Warp · 流明终端

Windows 中文终端项目，基于 [Warp](https://github.com/warpdotdev/warp) 和 [warp-cn](https://github.com/Heartcoolman/warp-cn) 社区分支。Lumen Warp 是独立社区项目，与 Warp 官方无隶属关系。

项目仓库：https://github.com/TianWen6654/lumen-warp

目前处于开发阶段。公开发行前必须完成源码和第三方资源核验、干净环境测试，并确定正式发布和更新渠道。正在测试的更新检查会查看本项目发布信息和社区源码，不会下载安装程序。

本项目基准为 warp-cn `a714a1ad833053db6f190f7fff38ecccc9fcd6ae`。修改补丁和源码归档仍在核验，尚未上传。仓库引用的 Git LFS 对象已从 Warp 上游取得并用于制作源码归档；依赖源码和许可证仍须核验后才能对外发布。

Warp 仓库中大部分代码采用 AGPL-3.0，`warpui` 和 `warpui_core` 采用 MIT；具体以各组成部分许可为准。第三方归属清单已压缩为 `THIRD_PARTY_LICENSES.txt.gz`。这些代码许可不自动授予商标使用权。
